# Sam Morris

I build practical web products for coaching, local communities, and the work behind them.

My projects connect useful information with clear next steps: finding a program, choosing equipment, exploring local courts, or getting in touch.

## Featured products

### Next Gen Academy

A website that helps families explore youth pickleball programs and find a starting point. It brings program and schedule discovery together with evaluation, lesson, registration, contact, and waitlist entrypoints.

Built with Next.js, React, TypeScript, and Tailwind CSS. The public code includes reusable session components and Playwright tests.

[Visit the site](https://nextgenpbacademy.com/) · [View public code](https://github.com/sammorrispb/nextgen-academy)

### Link & Dink

A pickleball product that helps players connect their equipment choices with their game and community. The paddle finder supports paddle identification, player preferences, and recommendations, with links to discover local groups and games.

[Explore the paddle finder](https://www.linkanddink.com/paddle)

## Business and community websites

### Sam Morris Pickleball

A coaching website that brings programs, inquiries, blog content, and a skill quiz into one place. Built with Next.js, React, and TypeScript, with fuzzy search and keyboard navigation in the public source.

[Visit the site](https://www.sammorrispb.com/) · [View public code](https://github.com/sammorrispb/sam-morris-website)

### MoCoPB — Archived

An earlier Montgomery County pickleball directory for finding courts and community information. It organized indoor and outdoor courts alongside location pages. The project is retired; its public repository remains an example of directory and local discovery work.

[View archived public code](https://github.com/sammorrispb/mocopb)
